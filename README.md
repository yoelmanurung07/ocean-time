# Ocean Time — Simulasi Sampah di Laut

Simulasi belajar interaktif tentang perkiraan waktu sampah bertahan di laut (Kertas & kardus, Kantong plastik, Botol plastik, Kaleng aluminium, dan Styrofoam) hingga 500 tahun.

---

## Cara Paling Mudah Menjalankan (Tanpa Ribet / Tanpa Coding)

Anda tidak perlu mengerti pemrograman untuk membuka website ini. Pilih **salah satu** dari 2 cara paling mudah berikut:

### Cara 1: Langsung Klik 2x Tanpa Install Apa Pun (Paling Praktis)
1. Buka folder ini.
2. **Klik 2x (double-click)** file **`Buka-Tanpa-Install.html`**.
3. Website langsung terbuka di browser (Chrome / Edge / Firefox / Safari) dan seluruh fitur simulasi, suara ombak, narasi, serta papan perbandingan langsung berjalan!

---

### Cara 2: Jalankan di `localhost:3000` dengan 1x Klik
- **Pengguna Windows:** Klik 2x file **`Jalankan-Windows.bat`**
  - Otomatis menyalakan server lokal dan membuka `http://localhost:3000` di browser Anda.
  - *(Jika komputer belum terpasang Node.js, file ini otomatis beralih menggunakan Python / membuka versi instan tanpa error!)*
- **Pengguna Mac / Linux:** Jalankan **`./Jalankan-Mac-Linux.sh`**

---

## Cara Manual (Untuk Developer / IT)

Jika menggunakan terminal dan Node.js:

```bash
npm install
npm run dev
```

Lalu buka `http://localhost:3000`.
